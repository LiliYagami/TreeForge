Fonctionnalités

Quatre outils, un workflow.

TreeForge couvre tout le cycle de vie d'un projet — de la création à la sauvegarde en passant par la restauration.

⚡

Générateur

Collez n'importe quelle arborescence texte (unicode ├──, indentation, JSON) et générez tous les fichiers et dossiers sur disque.

  • 3 modes de parsing (Strict · Souple · Confiant)
  • Contenu Vide, Minimal ou Boilerplate
  • Drag & Drop .txt / .json
  • Aperçu avant génération
📐

Templates

7 templates de projets prêts à l'emploi avec structure complète et contenu de démarrage.

  • Django · React/Vite · Vue/Vite
  • Node.js API · HTML statique
  • Python Package · MySQL
  • Contenu Boilerplate inclus
📦

Recaper

Exportez l'intégralité d'un projet existant en un seul fichier .txt — arborescence + contenu de chaque fichier.

  • Compatible IA (Claude, ChatGPT, Gemini)
  • Dossiers exclus configurables
  • 30+ types de fichiers supportés
  • Encodage automatique (UTF-8/16/latin)
🔁

RevRecaper

Restaurez un projet complet depuis un fichier recap modifié par une IA. Le cycle complet en quelques clics.

  • Recap → IA modifie → Restauration
  • Protection path traversal
  • Option écraser / conserver
  • Rapport détaillé

❓ FAQ
Windows SmartScreen bloque le .exe — que faire ?
Cliquez sur "Informations complémentaires" puis "Exécuter quand même". Le code source est auditable sur GitHub.
TreeForge peut-il écraser des fichiers existants ?
Uniquement si l'option "Écraser" est activée. Par défaut, les fichiers existants sont conservés.
Puis-je utiliser TreeForge sans connexion internet ?
Oui. Fonctionne entièrement hors-ligne.
Comment envoyer tout mon projet à une IA ?
Utilisez l'onglet Recaper — il exporte arborescence + contenu en un seul .txt. Puis restaurez avec RevRecaper.
TreeForge fonctionne-t-il sur Mac ou Linux ?
L'exe est Windows uniquement. Sinon clonez le dépôt et lancez python main.py (Python 3.10+).
